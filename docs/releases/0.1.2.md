Clearer menu edges and a slightly deeper selection blue, with the same black frame and pale blue tabs.

- Menus have a distinct gray border on black pages.
- White text on the selected blue now reaches 5.76:1 contrast.
- Native Firefox checks cover tab outlines, the address placeholder, selected address results, and hovered menu text and shortcuts.
- Generated manifests are checked byte for byte, including LF line endings.
- AMO compatibility checks retry temporary failures and report service outages separately.

The XPI and ZIP are unsigned packages for Mozilla Add-ons submission or temporary testing. The ZIP has `manifest.json` at its root; upload it directly without repacking. The source archives are for development.

Numerical and automated browser checks do not establish physical OLED behavior or complete accessibility coverage. See the repository's validation notes for the remaining manual checks.
